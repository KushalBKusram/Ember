A private AI that lives
on your iPhone.

Ember remembers who you are, reads your notes and files, and knows your calendar. It answers with Apple's on-device model, so nothing you type ever leaves your phone.

Build it yourself View on GitHub

Trust, by design

Cloud assistants see everything you type. Ember trades raw capability for trust.

Nothing leaves the device

No account, no sync, no analytics, no tracking. Your data lives in a local database on your iPhone.

It really remembers you

Facts come from your own words, are corrected when you correct them, and are fully visible in the Memory screen.

It shows its sources

Answers that used your notes or the web say so. Every source can be switched off.

It says when it doesn't know

Ask about your own life without a source and Ember tells you so, instead of guessing.

What it does

The core is small and held to a high bar. Everything experimental is labelled Beta.

Core

Private chat

Streaming replies on Apple Foundation Models, regenerate, edit, cancel, and an Incognito mode.

Core

Memory

Learns preferences, projects and relationships. Supersedes outdated facts. Writes a short, grounded profile.

Core

Files and notes

Import PDFs and text or write notes. Embedded and searched on-device with source attribution.

Core

Calendar and reminders

Read-only context at question time. Tells you plainly if access is missing.

Beta

Agents and scheduled jobs

Custom agents that run on a schedule and notify you with the result.

Beta

Web search

Opt-in and off by default. Questions about your own data never go to the web.

Honest about its limits

Ember is a single-developer, open-source project. Here is where it stands.

AreaReality
Retrieval accuracy58% top-1 on a 12-query evaluation set (Apple's built-in sentence embedding)
Duplicate memoriesParaphrased facts can be stored as separate entries
Scheduled jobsTiming depends on iOS background refresh (Beta)
HardwareNeeds Apple Intelligence: iPhone 15 Pro or newer, iOS 26+
Tests95 automated tests, run in CI on every push

Build it yourself

Ember is MIT licensed. You need Xcode 26 or later and an Apple Intelligence capable iPhone or the Xcode 27 simulator.

brew install xcodegen
git clone https://github.com/KushalBKusram/Ember.git
cd Ember
xcodegen generate
open Ember.xcodeproj
  1. Pick an iPhone simulator (or your own iPhone, with your own signing team) and press Run.
  2. Turn on Apple Intelligence on the device or simulator so the model can answer.
  3. Read CONTRIBUTING.md if you'd like to help. Issues and pull requests are welcome.
