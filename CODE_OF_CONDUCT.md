# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, welcome newcomers, and accept feedback
gracefully. Harassment, discrimination, personal attacks and other unwelcome conduct are not tolerated.

Maintainers may remove comments, commits, issues or contributors that violate this code. To report
a concern, open a private security advisory on the repository
(Security → Report a vulnerability) and mark it as a conduct report, or contact the maintainer
through their GitHub profile.
